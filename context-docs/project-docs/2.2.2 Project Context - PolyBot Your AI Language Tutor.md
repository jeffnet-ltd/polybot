## Executive Summary

PolyBot is an **AI-powered multilingual language learning platform** combining a structured **10-module CEFR A1 Curriculum** with AI-powered scenario-based practice for a "True Bilingual" learning experience. Users learn in their target language while receiving explanations in their native language.

**Current Status:** **Fully deployed to production.** Frontend live on Vercel, backend on AWS ECS Fargate behind a CloudFront HTTPS distribution, LLM inference via RunPod Serverless GPU, database on MongoDB Atlas. Google OAuth fully operational end-to-end.

```
    │
    └─── CloudFront (d2r1f6dy1chiig.cloudfront.net)
              └── Origin: ALB HTTP → ECS Fargate (polybot-backend:v1.6)
                        ├── MongoDB Atlas (TLS via certifi)
                        ├── RunPod Serverless (LLM inference)
                        └── Azure Speech Services (TTS)
```

### Why CloudFront?
The Vercel frontend is served over HTTPS. Browsers block XMLHttpRequest calls from HTTPS pages to HTTP endpoints (Mixed Content policy). CloudFront provides a free `*.cloudfront.net` HTTPS endpoint that terminates TLS and forwards to the HTTP-only ALB — no custom domain or ACM certificate required.

## Technical Architecture

### Stack Overview

- **Frontend:** React 18.2.0 + Tailwind CSS + Lucide React
    - **Deployment:** Vercel (https://polybot-sand.vercel.app)
    - **Build:** Create React App (`react-scripts 5.0.1`)
    - **API URL:** `REACT_APP_BACKEND_URL=https://d2r1f6dy1chiig.cloudfront.net`

- **Backend:** FastAPI (Python 3.11) — no local model loading
    - **Deployment:** AWS ECS Fargate (eu-west-2), image `polybot-backend:v1.6`
    - **HTTPS:** CloudFront distribution in front of HTTP ALB

- **LLM Inference:** Llama 3 8B Instruct GPTQ via RunPod Serverless GPU
    - Client: `backend/llm_client.py` (async httpx, 120s timeout)
    - Endpoint: RunPod `runsync` API

- **Database:** MongoDB Atlas (`polybot_database`)
    - Driver: Motor (async) with `tlsCAFile=certifi.where()` for ECS Fargate TLS compatibility

- **Voice:**
    - **STT:** OpenAI Whisper (local in container)
    - **TTS:** Azure Speech Services (`uksouth`)

- **Auth:** Google OAuth 2.0 via `authlib` + Starlette SessionMiddleware
    - Redirect URI: `https://d2r1f6dy1chiig.cloudfront.net/api/google/auth`
    - Post-auth redirect: `https://polybot-sand.vercel.app/?user_id=...&email=...&new_user=...`

- **Infrastructure:** Docker (ECS Fargate) + CloudFront + ALB

## Production Deployment — Image Build & Release Process

```bash
# 1. Build
docker build --platform linux/amd64 \
  -t 654654537596.dkr.ecr.eu-west-2.amazonaws.com/polybot-backend:vX.Y \
  ./backend

# 2. Push to ECR
aws ecr get-login-password --region eu-west-2 | \
  docker login --username AWS --password-stdin \
  654654537596.dkr.ecr.eu-west-2.amazonaws.com
docker push 654654537596.dkr.ecr.eu-west-2.amazonaws.com/polybot-backend:vX.Y

# 3. Register new task definition (update image tag in JSON)
aws ecs register-task-definition --region eu-west-2 \
  --cli-input-json file://taskdef.json

# 4. Deploy
aws ecs update-service --region eu-west-2 \
  --cluster polybot-cluster \
  --service polybot-backend-service \
  --task-definition polybot-backend:N \
  --force-new-deployment
```
